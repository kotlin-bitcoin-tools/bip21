# About

The `org.kotlinbitcointools.bip21` library is an implementation of the [BIP-0021 specification]. Until version 1.0, the API may still change between minor releases. Reviews and comments on the shape of the API are welcome. See the [issues] for discussion items and design decisions. The library is released under the Apache 2.0 license.

## Project Goals

The main goals of this library are:
       
  - [x] 1. Be BIP-21 compliant
    - [x] Encoding and decoding QR-ready strings
    - [x] Typesafe support for all standard parameters
    - [x] Unified QRs
    - [x] Payjoin
  - [x] 2. Well tested
  - [ ] 3. Well documented

[BIP-0021 specification]: https://github.com/bitcoin/bips/blob/master/bip-0021.mediawiki
[issues]: https://github.com/kotlin-bitcoin-tools/bip21/issues
